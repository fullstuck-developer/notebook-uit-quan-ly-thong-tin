# Hướng dẫn quy trình làm bài nhóm

Dựa trên cấu trúc mẫu của bài `BTTH2`, các thành viên trong nhóm thực hiện bài làm theo quy trình thống nhất sau:

1. **Tạo thư mục cá nhân:** Mỗi thành viên tạo một thư mục mang tên mình (viết liền không dấu, ví dụ: `PhamMinhMan`) bên trong thư mục bài thực hành hiện tại (ví dụ: `6BTTH/BTTH2/`).
2. **Làm bài cá nhân:** Trong thư mục cá nhân, tạo file Markdown mang tên bài thực hành (ví dụ: `BTTH2.md`) để làm và lưu trữ phần bài tập được phân công.
3. **Tổng hợp bài làm:** Sau khi mọi người hoàn thành phần việc của mình, tiến hành gộp tất cả nội dung lại vào một file chung của nhóm mang tên `Tên_<TênBài>_FINAL.md` (ví dụ: `PhamMinhMan_BTTH2_FINAL.md`) nằm ngay dưới thư mục bài thực hành.
4. **Nộp bài:** Dựa trên file `_FINAL.md`, xuất ra định dạng `.pdf` và gộp cùng các file `.sql` để nén lại thành file `.zip` nộp theo đúng yêu cầu riêng của từng đề bài.
